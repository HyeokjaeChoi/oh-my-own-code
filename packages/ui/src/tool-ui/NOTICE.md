The LinkPreview component is adapted from assistant-ui/tool-ui registry component `link-preview`, pinned to upstream commit `49a870286facdbf28160cd647f0d337ebdc9b275`. The source and its MIT license are retained in the repository spike at `spikes/sdk-ui/vendor/tool-ui/`. This app-owned copy keeps the upstream keyboard/navigation behavior and receives only payloads validated by `@workbench/contracts` before rendering.

Local styling diverges from that revision: component, aspect-ratio and image-fit utility classes are replaced by owned CSS Modules consuming the existing Primitive → Semantic → Component tokens. The card has a flat surface, no decorative image zoom, shadow or repeated outline, and no minimum width that forces narrow-layout overflow. Link activation retains Enter/Space and the sanitized navigation callback/default safe-navigation path; empty display metadata falls back to the safe destination for its accessible name. Serializable payload fields and the MIT license remain unchanged.
