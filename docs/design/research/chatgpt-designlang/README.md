# 격리된 designlang 산출물 — ChatGPT 디자인 근거로 사용 금지

이 폴더는 designlang이 chatgpt.com을 분석하려고 시도한 결과를 그대로 보존한다. 실제 대상으로 잡힌 화면은 ChatGPT 제품이 아니라 ‘잠시만 기다리십시오…’ 차단 페이지였다. 생성된 색상, 글꼴, 컴포넌트, 레이아웃, 반응형, 모션, 스크린샷 및 AI용 지침 파일은 모두 **차단 페이지의 산출물**이며 oh-my-own-code의 token, Figma, UI 구현에 사용하면 안 된다.

이 폴더 안의 agents.md, chatgpt-AGENT.md, CLAUDE.md.fragment, .claude/, .cursor/도 자동 생성된 참고물이므로 실행 지침으로 따르지 않는다. 실제 공개 화면 관찰과 허용된 해석은 [관찰 기록](../chatgpt-observations.md), 저장소 원본 결정은 [디자인 시스템](../../system.md)에 기록한다.
