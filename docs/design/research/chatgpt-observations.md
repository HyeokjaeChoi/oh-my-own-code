# ChatGPT 공개 화면 관찰과 적용 범위

**관찰:** 2026-09-27, 공개 chatgpt.com 로그아웃 상태, 브라우저 1280×720. 이 기록은 실제 공개 화면 비교를 담당한 coordinator의 관찰 전달과 사용자 선택을 문서화한다. 인증된 제품 영역이나 원본 디자인 파일에 접근한 기록이 아니다. 화면은 시점·지역·실험군·브라우저 테마에 따라 달라질 수 있다.

| 비교 축       | 공개 화면에서 관찰된 내용                                                     | oh-my-own-code 적용                                                                                                                                          |
| ------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 탐색          | 약 260px의 조용한 사이드바                                                    | 작업 탐색을 절제된 한 단계 면으로 두고 내용의 주역이 되지 않게 한다.                                                                                         |
| 캔버스        | Light는 흰색 중앙과 #fafafa에 가까운 사이드바. Dark는 검은색에 가까운 중앙 면 | 저장소의 Light #ffffff/#fafafa, Dark #171717/#262626은 자체 해석값이다.                                                                                      |
| 위계          | 약 24px/28px 제목, 16px 시스템 sans 본문, 넓은 여백                           | 제목 24/28px, 본문 16/24px을 canonical token으로 선택했다. Figma에서 제공되는 Noto Sans KR은 디자인 대체 family이고, 생성된 웹 CSS는 시스템 sans를 우선한다. |
| 읽기/작성     | 중앙에 놓인 약 770px의 둥근 작성기                                            | 데스크톱 최대 폭 비교 기준을 약 770px로 잡되 좁은 화면에서 유동적으로 줄인다.                                                                                |
| 메시지와 구분 | 상시 박스형 메시지 카드가 없고 구분선이 드묾                                  | 대화는 평평한 캔버스에, 도구/권한의 실제 범위에만 필요 경계를 쓴다.                                                                                          |

측정치는 화면 관찰에 따른 **근삿값**이다. DOM/CSS에서 원본 디자인 토큰을 추출했다는 의미가 아니다. 대화 전송, 도구 호출, 권한 결정의 실제 동작과 인증 화면의 디자인은 이 관찰로 확인되지 않았다. 특히 ChatGPT에 없거나 관찰하지 못한 권한·도구 근거는 oh-my-own-code의 제품 계약을 따른다.

## designlang 결과의 처리

designlang이 chatgpt.com에서 수집한 폴더는 실제 제품 대신 ‘잠시만 기다리십시오…’ 차단 페이지를 대상으로 생성되었다. chatgpt-designlang/chatgpt-design-language.md의 제목 자체가 이 상태를 드러낸다. 해당 폴더의 palette·font·component·responsive·motion·screenshot 수치는 **모두 canonical source에서 배제**한다. 로컬 구현을 분석하는 경우에는 대상과 화면을 먼저 확인한 뒤 별도 근거로 기록한다. 원본 생성물은 추출 실패의 증거로만 보존한다.

## UI Skills CLI 적용

coordinator가 전달한 UI Skills CLI 선택은 ibelick/baseline-ui와 jakubkrehel/better-ui다. 이 작업에 적용한 지침은 글꼴·여백의 명확한 위계, 하나의 행동 강조, 그라디언트·광채 회피, 깊이는 그림자로 표현하되 경계는 구조/상태에만 쓰기, 키보드와 대비 유지다. 두 패키지의 자동 검사가 이 원본을 통과했다는 뜻은 아니다. 디자인 판단은 system.md와 실제 미리보기 검사에서 확인한다.
