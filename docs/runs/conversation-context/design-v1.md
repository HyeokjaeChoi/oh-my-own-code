# Conversation context contract
Version: 1 · Proposed initial major design

## 1. User flow and existing ownership
Keep assistant-ui conversation and one Zustand owner. Composer adds a compact context list and explicit add-file/reference actions, with name, source, type, exact bytes, captured version/hash, remove, and preview. All reads/picks/previews are explicit. Workspace attachment path stays within selected canonical workspace; reject protected source and path escapes. This release increment does not silently add external-folder, remote URL or directory attachments. Text preview uses inert escaped text preserving BOM/CRLF; image preview uses locally held inline bytes only; PDF has metadata/byte/hash preview with explicit content-preview-unavailable label, no embedded script/URL privilege. Text selection preview identifies captured lines/range and version; not current file after source change. Existing line feedback selection remains supported and is not invented from paths.

## 2. Closed snapshot capability and byte IO
A private host module prepares immutable byte snapshots through held checked-root/ancestor/leaf descriptors, pre/post identity/time/size/hash checks and check callbacks. Reuse existing protection and IO observation primitives; no unchecked reopen of original path and no creation/write. Refuse symlink/hardlink/nonregular/protected/missing/denied/changed sources. Allow UTF8 text (64KiB per text), PNG/JPEG/GIF/WebP/PDF (8MiB each), up to8 items and16MiB total per send. Reject BMP/AVIF/SVG/audio/video/unknown binary explicitly. Bounds checked before read/allocation; no partial successful list on limit or change. File extension/renderer MIME is not authority; actual bytes classify type. Invalid decodable image is refused where built-in Electron image validation is available; remaining SDK format rejection stays conservative unknown after dispatch, never confirmed none.

Host memory cache is per sender/epoch with opaque capability IDs and immutable ordered descriptors (name/source/path/version/digest/mime/size). Cache<=64MiB raw total per window,<=64 entries,10min inactivity expiry. Pin during actual Native call; timeout/lookup cannot release actual-call hold, no pinned eviction. closeSender/epoch revokes reuse; shutdown settles actual tasks before cleanup. No persistent attachment copy, base64 in journal or payload in retained keys. Renderer cannot supply arbitrary URI or replace host bytes. Cache expiry/restart leaves editable inert draft summaries but send requires explicit re-observation; never automatic file reread. Cache and descriptor API names are proposals until Main actual source checkpoint; consumers must not consume this prose as frozen DTO.

## 3. Send and truthful source reports
Normal send includes ordered closed capability descriptors. Host checks sender+epoch+scope/root/current trust/baseline and exact cached descriptor/bytes before effect, computes canonical original operation digest over complete request and expectedRevision, and keeps immutable dispatch selection. Host constructs canonical base64 data URI from captured bytes with safe display name; Native never sees original file URI. Attachments require explicit currently available model and closed actual capability support (text/image/pdf); missing capabilities block attachment send. Preserve both baseline policies and post-selection verification. Current Native uses prefix modality support; app must use a documented closed matching rule consistent with actual source, never guess universal support. Unknown operation lookup exposes original key/status only, never fabricated context body or replay authority.

Preview is the captured input sent to Native, not proof of bytes seen by provider. Actual Native prompt hooks may transform input and image normalization may change image bytes. Existing exact text receipt validation remains; attachment result projection must distinguish original request from current Native-reported message attachments and must not export arbitrary original URI/private metadata. Historical attachments are inert/read-only if safe bounded bytes cannot be established. No thumbnail network requests, unsafe HTML, automatic provider upload, or claimed model execution from ACK.

## 4. Retry and edit boundary
Use existing session.fork with additive explicit before=userMessageId; validate fresh target membership/role in original Native session and exact returned fork.boundary={type:before,messageID} plus existing ID/location/metadata/digest mapping. Retry/edit first shows the selected user request and the boundary, explains current workspace files remain as-is, then creates the branch only. Native revert/file restore is not called. On confirmed branch, populate original/edited text and attachment descriptors only where current original capability exists; expired/historical context is shown unavailable and requires explicit selection. User explicitly sends from new branch; old tools are not replayed and original session stays unchanged. Baseline permission policy applies to new run; prior approvals are not transferred as new execution permission. Pending/unknown fork keeps original key lookup and never guesses child ID or auto sends. Generic latest-history fork remains separately named existing action.

## 5. Running steer and queue
Provide explicit current-run extra instruction and queue actions, visually separate from editable F06 next-send options. These requests omit agent/model/variant switches and clearly say they use Native's current run/session setting; neither a UI choice nor cached report proves actual model. Host current health/trust/scope/unknown checks and both policy stages remain; no implicit conversion from normal idle-only send. Actual request delivery steer|queue is part of original digest and checked SDK response. Native inbox observation is bounded/session-correlated, explicit and read-only; pending entries are not final delivered messages. Fresh exact pending-ID cancellation uses actual SDK call, records flush-before-effect and original identity, and labels ACK as cancellation request accepted. Absence alone never proves cancellation or nonexecution; racing delivery/error/unknown remains explicit and no replay. Never drain/reopen nonfresh pending store, replay queue on restart, or silently move a request to another session. If a new cancellation operation/dispatch is needed, coordinate a closed feature marker and current/archived parser refusal before consumer freeze; do not privately alter journal APIs.

## 6. Verification and permitted execution
Main exact checkpoint precedes renderer/fixture/storage consumption. Meaningful production-module REDs, then tests including real synthetic filesystem IO and actual admission/registry correlation. Existing state/IO guards remain. Focused hidden production renderer/preload with synthetic Main, original full PNG, postpaint/hidden/nonfocusable/normal-owned-exit and current source/build/native/script before-after hashes. At200% expose each clipped value and final controls, not only summary; invoke current actual legacy geometry where its layout is affected. Do not run unrelated entire UI families on a runner-only fix. Input_scope includes recursively read token CSS and actual build/staging dependencies; final reviews stay whole-source.

A future saved auth-free Native compatibility probe may create only fresh contained synthetic namespaces using actual pinned production owner/registry/supervisor helpers and freshNativePreflight. It must ensure no active execution and use SDK prompt resume:false, verify active remains empty, inspect admitted inline bytes/mime/delivery through actual SDK, then stop owned child and retain namespace. No credentials/provider/model execution, production Main, existing stores, real Documents, foreground/clipboard, arbitrary global binary or Native DB schema writes. This demonstrates Native materialization/inbox compatibility only, not production host/provider end-to-end execution. Exact implemented invocation/source/provenance must be reviewed before Main executes it. Windows and provider/release acceptance remain separate. Entry PLAN/DESIGN pass is not runtime proof.
