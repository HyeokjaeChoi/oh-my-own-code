# Existing text-file editing design v3

## Boundary and alternatives
Use the existing descriptor publisher for a separate existing-only `file` target. One publisher owns stage/token/exchange/backup/cleanup, one registry owns original identities and one Renderer store owns drafts. A new fs.writeFile writer duplicates safety and loses original target evidence; Native/model/tool writes add execution authority to a direct file editor. Neither is selected. Keep legacy module names and old public operations; avoid unrelated refactoring.

## API and data
`file.edit.read {workspaceId,path}` is an explicit workspace-only normalv2 read with sender. `path` is portable relative metadata, never an absolute renderer authority. A closed observation includes runtimeEpoch, revision, workspaceId, workspacePath, path and host-derived targetPath. Available adds exact `content`, 64hex `version` and `directoryVersion`. Unavailable/unsupported has a closed reason and no content/version. Missing existing file is unavailable, never a creation baseline. Root/path/text limits and protected-source policy are defined in plan. Helper validators return the same validated DTO; host creates detached bounded values.

`file.save` carries workspaceId, path, requestId equal to outer operationId, expectation:`version`, version, directoryVersion and exact text. Digest includes immutable type/scope/path/baseline/text. Normalv2 envelope supplies current admission epoch; retained original keys remain original. Completion adds `file_saved` with exact workspace/path/version/digest/backupId correlation; no text in journal, receipt or retained intents. Public result has requestId/status saved|unknown, version/backupId only on verified saved. Errors use existing FILE_* codes and closed new reason mapping as necessary, not raw IO output.

## Host authority and publication
Pure path checks precede IO. Acquire canonical root then every existing ancestor with no-follow descriptors, same-device and named dev/ino checks around awaits; acquire single-link regular source and exact bytes/stat version. directoryVersion binds ordered canonical ancestor dev/ino plus workspace/path. New generic observer reuses version/identity primitives with an explicit kind/path; never reinterpret Skills sourceName as arbitrary path.

For save, require ready owner, registry/trust/recovery/resource authority and freshly idle exact mapped workspace sessions/no inbox/pending permission via existing read-only SDK identity calls. Hold workspace lock before confirmation. Confirmation shows full actual target, local file replacement, exact content comparison and backup retention. No Native apply/reload/execution is implied. Recheck source and complete ancestry after confirmation before durable stage intent. Before creating any stage file for generic kind=file, open the original through the held parent descriptor with O_RDWR|O_NOFOLLOW|O_NONBLOCK|O_CLOEXEC, verify the same baseline identity and close without writing. Never use O_CREAT or O_TRUNC on the original. The read baseline stays O_RDONLY. This requires actual original-file write permission in addition to directory replacement authority; do not infer authority only from mode bits. Permission refusal before dispatch is FILE_DENIED; unproved failure after a flushed dispatch stays original-key unknown. Existing configuration target permission behavior remains unchanged. Descriptor publisher receives immutable exact target/baselines, existing-only expectation and bounded text. Stage/publish follow existing flushed intents and token checks. Recheck owner/root before and after publication; final exact source reread, bytes/version/backup proof before confirmed receipt.

Abort/timeout cannot cancel already dispatched publication or cleanup. A predispatch conflict keeps file and draft, returns FILE_CHANGED; any unproved postdispatch outcome holds original key as unknown. No resubmit action for retained payload. The shared publisher retains original content/backup according to existing rollback rules. Named feature marker precedes first new admission; archived original parser must reject new journals without mutation. No Native process starts for actual descriptor probe; staged bundled Bun executes only synthetic paths.

## Renderer and user flow
File tree selection/preview remain usable. Add a separate explicit editor surface through the files panel: `편집용으로 열기`, plain multiline text, byte count, `내용 확인`, `파일 저장`, `초안 버리기`, read/save status and exact selectable target. Loaded text is the write baseline; no automatic open/read/save on selection, poll, start, refocus or resize. General text validation must not claim language correctness. Protected source explains dedicated editor; untrusted guide truthfully uses existing explicit trust path and its new-session side effect, no invented trust action.

Drafts live in the sole window workbench owner keyed by epoch/workspace/path with canonical root in authority. Bind asynchronous read/hash/save to epoch/root/trust/floor/generation/selection generation/exact draft reference. Selection ABA or late ACK never changes another draft. Retain editable/selectable text during holds without IO authority. Success advances floor and invalidates baseline until explicit reread; preserve a newer edited draft. Unknown uses original composite operation key/current lookup envelope and cannot replay or clear holds through ordinary polling. Navigation, preview and other drafts remain accessible.

Use existing A Quiet Dock tokens, wraps, focus and responsive panel/drawer. Status region exposes ready/loading/changed/saved/unknown/denied/unavailable; full safe target remains selectable. Escape cancels pending read and moves focus to status; save dispatch is not falsely called cancelled. Desktop and actual760px/200% show controls without horizontal overflow, preserve draft selection and keyboard order. No hidden process controls or implementation IDs in ordinary copy.

## IPC byte budget
Existing save IPC cap remains262144 encoded JSON bytes. Editable raw UTF-8 limit is65536 bytes, independent from existing preview256KiB. Valid text contains no binary controls; worst-case quote/backslash/newline/tab JSON escaping at most doubles admitted raw bytes. Bound root4096UTF-8 bytes, relative2048, key128 and metadata. Shared write-fit plus exact full prepare-message validation/test must guarantee all admitted maxima fit the unchanged cap; never claim raw-byte-only limit suffices or silently raise IPC.
