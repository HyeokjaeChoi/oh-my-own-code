# Selected-session instruction registration design
Version: 2 | 2026-10-08

## Scope, API and current evidence
Root AGENTS.md only, selected registered/trusted app session. Actual SDK session.instructions.entry.list returns key/value, put/remove void. Key omoc.project-instructions fits actual lowercase key schema. Native fork copies entries; keep one constant key. Preserve private process/closed loader/security architecture. No generic config reload, MCP or provider call. Current-session registration is useful independently, but not fullF14. Source facts name pinned paths/hashes and exact old journal parser.

## Closed read and mutation proposals
configuration.instructions.read {workspaceId,sessionId} is explicit read with current v2 sender/readId/epoch, no Native text projection. Result includes scope and status missing|registered|changed|unavailable, observed version hex64 for actionable states, digest only for present owned supported string, optional sourceVersion and closed origin direct|fork (inheritedFromSessionId only for fork) from matching registered durable metadata, and closed reason for unavailable. Native ownership is never inferred from a UI label.

configuration.instructions.apply {workspaceId,sessionId,requestId,text,fileVersion,expectedRegistrationVersion}; remove {workspaceId,sessionId,requestId,expectedRegistrationVersion}. Same v2 operationId/expectedRevision. No key/path/approval from renderer. Apply text must satisfy existing supported instruction disk-text/UTF16/UTF8<=32768 predicate, include exact BOM if present, and equal independently read file content/version. Missing/unsupported file cannot apply; blank file may register an explicit empty string with clear confirmation. Remove changes only the app entry and does not require reading or deleting AGENTS.md. Exact final public union field names are frozen in actual source before consumers.

## Ownership, baseline and drift
Optional session record instructionRegistration is closed: {state:registered,key:omoc.project-instructions,digest:hex64,sourceVersion:hex64,origin:direct} or {state:registered,key:omoc.project-instructions,digest:hex64,sourceVersion:hex64,origin:fork,inheritedFromSessionId:appSessionId} or {state:absent,key:omoc.project-instructions}. Direct origin forbids inheritedFromSessionId; fork origin requires the exact immediate parent appSessionId from the completed verified fork. Native owns text; no raw text or unrelated entry value in journal/DTO/logs. Missing optional field denotes never-owned legacy/empty session. First mutation requires missing reserved Native key; existing reserved key without durable ownership is unavailable ownership_conflict and cannot be taken over. Once durable ownership exists, present Native string digest mismatch or absent/present drift is status changed. User can explicitly repair/remove that owned key only after fresh baseline+confirmation. Do not adopt arbitrary other keys.

Content digest SHA256(exact UTF8 string). Baseline version SHA256(canonical JSON array of [reservedKey, durable ownership metadata or null, observed absent or supported-string digest]); it includes state/sourceVersion, not just text. Baseline is observation, not CAS. Host bounds list array<=64, duplicate/malformed reserved key refuses; app string<=32768, well-formed UTF16. No other key/value is copied to renderer/logs. SDK may allocate/decode before these post-response checks; do not claim network hard byte isolation. Unowned other keys remain untouched and may also affect Native context.

Main confirmation uses immutable session/workspace/target path, text digest/current baseline/replacement or removal effect. Recheck everything after await. Denial or baseline/file mismatch before dispatch completes rejected/none.

Flush new allowlisted native.instructions.put/remove step before exact SDK call. Do not extend the renderer's authority. Re-list exact key after ACK and verify current correlation, idle/pending state and baseline permissions. Confirm only exact intended string digest or exact absence, then durable completion with matching metadata delta and closed instruction_registered/instruction_removed receipt carrying workspace/session/digest/sourceVersion as applicable. Do not project speculative success before flush, including timeout/error redaction. Any post-dispatch error, mismatch, channel/lifetime loss or completion failure is unknown original key/resource hold; no replay/reapply, rollback or automatic retry. Registration may already have changed even when unknown. Same-UID external races between checks are not excluded; current post-read is not future stability/CAS.

## Persistence, compatibility, fork and subsequent effects
Feature marker configuration_instructions_v1 precedes any new admission or instructionRegistration delta. Reuse existing journal, registry serialized steps and checkpoint; pre-marker expectedRevision semantics preserved. New reader rejects impossible feature/operation/delta associations. Actual prechange configuration-save journal parser must refuse marker and referencing checkpoint unsupported_version without modifying bytes. No parallel config journal. Operation result only confirmed matching dispatched/accepted type, original key/session/digest; redaction excludes raw text/path.

New empty sessions have no registration. Native fork copies one key; host copies the parent digest/sourceVersion after parent baseline verification and child post-fork exact entry verification, records origin:fork and immediate inheritedFromSessionId bound to the completed fork. Confirmed child apply always records origin:direct and removes inheritedFromSessionId even for identical text/fileVersion; confirmed remove records absent without origin. Denial/no-effect leaves origin unchanged; unknown never exposes a speculative origin change. Failure after fork stays unknown/partial mapping under existing rules, never silently clear inherited context. Do not modify Native's existing exact metadata correlation object. Hydration preserves optional session metadata. Restart reconciles existing Native entry by read only; no automatic put/remove, even if app and file agree. Registration-sensitive message.send/command.run/session.fork verifies app-owned current digest/absence before effects; drift refuses until explicit repair. Other metadata controls remain independent. Keep both baseline policy stages before/after agent/model selection intact. Original operation lookup is the only unknown reconciliation path.

## Sole window state and UI
Reuse one authoritative store and operation-key owner. Registration state is scoped per app session; file draft remains workspace/kind scoped. Capture immutable epoch/path/workspace/session/draft revision/text/fileVersion/baseline/floor. Explicit observe button obtains Native metadata; no automatic file read or mutation on poll/load/save/selection. A new request replaces only its own binding. Late ACK updates historical original operation/scope; newer draft/selection/discard/ABA are not cleared or revived. Lookup-only retained keys never fabricate text or replay. Resource/global authority disables dependent mutations while leaving draft/navigation/selectable paths usable.

Show exact selected target/session, file observation version, current registration state/digest and whether current draft/file differs. Labels distinguish file saved, instruction entry registered for current session, next context preparation, and model consumption not yet verified. Removal leaves file/history and cannot erase old model context. Show inherited state only from current matching Native observation plus durable origin:fork and verified inheritedFromSessionId recorded at fork completion; never infer from present parent digest or parentSessionId alone. Parent later changes do not relabel the child. Hydration/checkpoint and read baseline include full closed origin metadata. Same-content explicit apply is direct even after restart; no guess from path/name. Existing tokens desktop32/coarse44/permission36/focus3:1/reflow; keyboard and standard760px/2x plus optional narrow360 stress. Explicit status for denied/drift/unavailable/unknown, no fake active model indicator. Do not continue claiming runtime application unavailable after this feature is present; state supported selected-session scope and remaining other categories/MCP truthfully.
