OpenCode event host feasibility — phase1 design v3

Purpose: prove persisted events/idle synthetic history using official server2.0.18 option. No production replacement or automatic pending recovery claim.
Runtime/topology: Node24.14.1 controller -> one fixed Bun1.4.2 child -> official server/core2.0.18; client2.0.18 uses authenticated loopback HTTP. One actual Scope per child, close + exact exit before reopen. No UI.
Inputs: fixed version/hash/integrity/manifests, full dependency/native/WASM/migration inventory. Existing35 P7 sources/current packaged artifacts unchanged. All actual prototype files become environment_files with refreshed entry before runtime. No in-check selection/input mutation or fallback.
Installer: allowlist env and own HOME/cache/tmp/npm user/global/project configs before metadata/lock/download/install. Public npm registry only, inspect resolved URLs/scoped overrides, no credentials/proxy/NODE_OPTIONS inheritance. audit/fund false, scripts ignored, workspaces false. Exact native hook may run only after documented reviewed input policy; no blanket scripts. Validate Bun platform archive integrity and extraction containment.
Child: explicit owned env/config/data/state/cache/tmp/cwd/database, config.projectfalse, empty config/no plugins/MCP/providers, model fetch/watcher/fff false, baseline deny. Private password via owned IPC only. Reports discard raw child output and redact password, token, cookie, code, ticket and secret URLs; no tokens issued here.
Paths/API: startup path manifest lists canonical mutable namespace roots and immutable runtime/package/system-library read roots. Before each spawn or SDK/HTTP operation reject noncontained path, symlink, hard-link alias, .., URI, wrong UID/mode; new files validate nearest existing ancestor then recheck. Synthetic sibling negative fixtures never sent outside allowed root. Closed methods: server.info; session create/get/update title+metadata+denied-permissions only; session messages/export/import/log; no arbitrary method/payload. Import own bounded text-only fixture with exact ID/location/metadata checks; no attachment/path reference or pending job. Guard test requires ZERO rejected Native call/spawn. This is a caller/path guard, not OS sandbox or all-engine filesystem proof.
Basic/CORS request table for ordinary API after ready: missing or wrong Basic ->401; valid Basic with no Origin ->200, no Origin credential/cookie simulation; valid Basic controlled http://127.0.0.1:<port> Origin ->200 with matching allowed-origin header; valid Basic https://fixture-rejected.invalid ->200 without allow-origin header (CORS denial is not API auth denial). If pinned middleware actual behavior differs, fail and reconcile against primary code, never manufacture success. Pairing/ticket/cookie flows are NOT invoked or declared qualified. Raw credentials/body/URL values absent from report; labels/status/header-match booleans only.
Ownership: actual ChildProcess identity/ready/exit, direct causal handle proof for observed descendants. Before idle SIGKILL ensure all acknowledged calls settled and known descendants exited; no tool/PTY/shell/provider-producing APIs. Startup failure/timeout/disconnect: explicit scoped stop, bounded exit wait, then force only exact own handle if needed; retain on unconfirmed identity/exit/observer gap. Never kill unknown PID or reuse uncertain namespace. Parent-observed exit is not historical standalone ownership. No descendant/OS-effect universality claim.
Event/history: full history omits after, includes actual seq0; after c means strictly seq>c. Marker separately correlated, nonempty required payload and version/type/aggregate/data IDs/canonical hashes verified, allow only documented sequence gaps. Actual create/rename/import/metadata events from official APIs, no synthesized log. Compare committed prefix, text-only synthetic transcript, exact mapping/location and real keep.txt after normal and owned idle SIGKILL reopen. Unconfirmed final request remains unknown. All durable evidence retained.
Limits: this phase has no queued/suspended/shell/subagent states or provider attempt instrumentation, thus NO safe nonfresh-start claim for such states. Production fresh-only and owner holds unchanged. No staged distribution/desktop/Windows/publication/migration or power-loss proof. General server pairing/ticket/PTY/outbound security awaits production concern. EH01–07 only; P7 eleven checks and PRD unchanged.
