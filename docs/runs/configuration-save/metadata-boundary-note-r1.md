# Main discovered metadata race - proposed narrow correction

Whole fcopyfile XATTR uses a live source descriptor. A concurrent writer can enlarge/add attributes after the bounded snapshot check and before copy, making that bulk syscall copy more than the stated aggregate32KiB cap. Existing primitive success does not establish a race bound. Use bounded flistxattr/fgetxattr snapshot buffers and fsetxattr for each known opaque value instead. Snapshot size32KiB/names32, no buffers allocated from unchecked length, ERANGE/missing/metadata mismatch conservative unknown. Stage default OS attributes must be compared/removed only when exact known bounded attrs and held stage FD (no pathname delete), then exact source snapshot copied to stage and hash verified. Unknown special profile remains refused. Source/body/mode/ACL/flags rechecked before and after publication. This is an implementation correction retaining same original-target architecture; no new user scope or second metadata journal. Current DESIGN_SPEC reviewer was informed before verdict; initial review report will be preserved before updating documents/binding.
