## Design direction and bounded v1 scope
Under prior autonomous design delegation, propose a quiet, high-readability developer workbench: neutral surfaces, restrained blue accent, information hierarchy from typography/spacing, limited borders for interactive boundaries, clear semantic status. Korean-readable UI with original technical identifiers. Light/Dark semantic modes. No inherited MealTicket theme or unrelated wallet system. Repo tokens are the source for values; Figma mirrors tokens/components; no bidirectional sync claim. Independent contract review before Figma consuming components.
First coherent system increment: primitive → semantic → component tokens, CSS export, typography/layout/motion/a11y/state guidance, and six component families: Button (primary/quiet/danger × default/hover/pressed/focus/disabled/loading = 18 variants, one base 40px size), Input (default/hover/focus/disabled/error = 5), StatusBadge (queued/running/waiting/success/error/unknown = 6), NavigationItem (default/hover/selected/focus = 4), ToolCall (queued/running/waiting/success/error/unknown = 6), PermissionRequest (pending/sending/approved/denied/stale = 5). Total 44 variants. Core families are v1 foundation, not all production app components or completed flows. Cover, Getting Started, Foundations, component pages, Utilities guidance. No production UI, backend coding or Code Connect mapping until real app components exist. Record that mapping is not applicable, not complete.
Exact token names/values/type/scope/CSS syntax and family contracts are authored locally and frozen in a manifest before Figma token/component writes. Fonts are selected from actual available fonts; Korean family and monospace must be verified before text writes. If chosen font unavailable, use a verified suitable family and record decision before freezing, not silent approximation. Contrast >=4.5 normal text, >=3 nontext/focus and large text; disabled exception explicit; statuses have text labels; inline permission cards do not trap focus. Responsive widths and reduced motion are contract guidance, not runtime proof.
