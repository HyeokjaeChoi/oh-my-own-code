## 주요 제안

두 고정 합성 자료를 같은 읽기 도구로 관찰한다. 예제별 ask 허용/deny를 대화 복사 없는 새 세션에서 순차 실행한다. 도구 미호출은 비교 부적격, deny 중 도구 시작은 정책 실패다. 설정 근거·런타임 관측·설명용 추론과 실행 상태·기록 완전성을 분리한다.

학습 평가는 예제별 네 문항, 문항당 1점이며 각 예제 3/4 이상과 Q2 정답을 제안한다. 같은 문항으로 문서/CLI 기준 방식과 UI를 비교하되 연습·순서 효과로 인과 효과를 주장하지 않는다. 예제별 10분, 명시적 재시도 최대 한 번, 실패·축소 검토 조건을 고정했다. 이 상세 규칙은 PRD 승인 대상으로 제안한 것이며 사전에 사용자가 지정했다고 주장하지 않는다.
