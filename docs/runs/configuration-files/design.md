# Configuration file loading — design v2

This contract extends the existing in-window editor with an explicit real-file read. No persistent write or Native activation is introduced.

## Public host boundary

Request: configuration.read {workspaceId, kind:instructions|mcp} inside existing v2 read envelope. Main binds registered canonical workspace, read caller/deadline and derives AGENTS.md or opencode.json. Response: {workspaceId,workspacePath,kind,path,status:available|missing|unsupported|unavailable,content?,version?,reason?}. available alone includes bounded content and hex64 version; all other statuses omit content/version. Reasons: missing_file, path_denied, file_changed, too_large, unsupported_content. Status/path are observations, not Native active state.

Read up to32768 bytes plus one overflow byte; reject non-file/symlink/hardlink, invalid UTF8 and forbidden controls. Hold root FD and file FD through checks; compare dev/ino/size/mtimeNs/ctimeNs before and after plus pathname canonical identity. Check current admission before/after awaited IO. Fixed target does not follow renderer paths. Missing means confirmed root identity and target absence at observation; no promise about future writers. Version includes observation identities/timestamps+raw byte SHA; no CAS/write success claim. Do not use lstat-only size checks or assume one read fills buffer.

MCP strict JSON must reject duplicate member names in every object, comparing decoded Unicode-escaped names, then pass exact shared supported-subset validation before any raw text is returned. No unsupported credential/unknown fields or parser error value is exposed. Whole-file refusal preserves original file and current draft. AGENTS.md explicit local read follows same text/size bounds; empty instructions file can be available even though new draft validation later asks for content. No automatic file read/catalog read/SDK config.get. No permanent raw document cache.

## Renderer ownership and reconciliation

Existing sole window store owns per-workspace/path/kind draft and optional last loaded observation plus request identity/status. Controller creates abortable explicit read; no poll/subscription-triggered content read. Begin read captures selected registered workspace/path, runtime epoch, kind, current draft revision and monotonic request generation. Validated response must exactly match fixed target identity. Only still-current unchanged draft may be replaced. Later edits or selection/epoch/path change abort/discard old read. Store requires the exact immutable active request identity still present in the selected entry. Discard aborts and removes that identity; revision0 reset or same-key recreation cannot revive it. Late success and error after discard are ignored. A newer same-kind request supersedes old response; failed/stale responses keep text/baseline. Loading explicitly replaces text, sets loaded baseline, clears validation and increments revision. Capacity/revision limits remain nondestructive. Existing memory baseline action clears disk provenance without changing current text.

The load control is named '파일 불러오기'. Explain that it replaces this selected draft and reads only the stated file. Loading/status is separate from format validation and Native state. File status and last loaded version observation are readable; unsupported files offer fixed explanation, no raw preview. Comparison labels '마지막으로 불러온 파일 기준' versus '이 창의 메모리 기준'; warn that external edits after read are not monitored. No enabled apply/connect button is added. All existing drafts remain temporary; narrow keyboard targets follow desktop32/coarse44 and current focus/reflow tokens.

## Checks and failure behavior

Host synthetic fixtures: valid/empty AGENTS, supported strict MCP, missing, unsupported JSONC/root/provider/header/environment/OAuth canaries, duplicate root mcp/servers/server/option keys including Unicode escapes, symlink/hardlink/binary/oversize and deterministic file/root changes during read. Contract rejects unknown kind/arbitrary path. Store/controller late races across edit/selection/epoch/same-id path/reload request, capacity, discard at revision0 with late success/error and same-key recreation, failures and zero mutation. Hidden actual built renderer/preload with synthetic Main exercises explicit instructions/MCP loading, disk diff, edit-invalidates validation, unsupported-preserves draft, panel retention and narrow200 keyboard/scroll. Separate independent code and selected original-pixel review. No real config/credentials/provider/production Main/Native invocation.

Later file apply must compare this version with current bytes/identity and use durable effect intents; this read design does not authorize implementing an unsafe check-then-overwrite or changing Native project:false. SDK location.reload void ACK is never observed active proof.
