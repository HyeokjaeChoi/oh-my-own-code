# ASO evidence and output

Use official store documentation for current metadata fields, limits, policies, and experiment mechanics. Record each source and verification date.

For third-party keyword or market data record provider, market, locale, date range, query/filter, and whether the value is measured, modeled, or estimated. Never invent search volume, difficulty, ranking, conversion, or competitor performance. A keyword without measured data is a labelled hypothesis.

Build positioning from:

- audience and recurring situation;
- specific problem and current workaround;
- benefit the implemented product can prove;
- differentiator supported by product or research evidence;
- search intent and locale vocabulary.

Return metadata organized by the store's exact current fields. Include the verified character limit beside each field while drafting, then remove counting aids from final copy where appropriate. Check prohibited or unsupported claims, duplication, truncation, grammar, and localization fit.

An experiment proposal names one hypothesis, eligible locale or page, variants, primary store outcome, guardrail, start condition, minimum observation window or decision rule, and what action follows each result. Separate uploaded, running, completed, and interpreted states.
