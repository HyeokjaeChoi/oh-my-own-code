# Store visual assets

Verify current official App Store or Google Play requirements for the selected target immediately before export. Record the source URL and verification date; sizes, formats, and device classes can change.

- Apple: [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) and [upload workflow](https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots).
- Google: [Preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en) and [store listing experiments](https://support.google.com/googleplay/android-developer/answer/12053285?hl=en).

## Capture provenance

For every source capture record the app version/build, platform, device or simulator, OS, locale, theme, route/state, demo-data source, capture date, and file path. Remove personal data, debug overlays, unstable timestamps, unrelated notifications, and secrets. Preserve honest product behavior.

## Storyboard

Order frames as a product story rather than a component inventory. Each frame has one benefit, one product state that proves it, concise localized copy, and an explicit role in the sequence. Do not promise behavior the source build cannot demonstrate.

Keep product UI readable after store scaling and safe-area cropping. Device frames, backgrounds, annotations, and promotional illustrations support the capture; they do not replace it. Label concept art or mockups in the manifest.

## Export and verification

The manifest records store, locale, device class, order, message, output file, pixel dimensions, format, source capture, build, requirement source/date, and status. Check actual file dimensions and format, cropping, text rendering, ordering, locale completeness, and legibility. Open representative final assets for visual inspection.

Keep editable composition sources and external font/image/template licenses discoverable. Distinguish prepared, exported, uploaded, submitted, approved, and live states.
