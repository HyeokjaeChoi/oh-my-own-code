# Extension observation contract
Version: 1. New closed read projection; existing architecture/tokens unchanged.

## Private and public read
The fixed bundled plugin adds one allowlisted authenticated observe method. Wrong nonce/extra fields/wrong canonical context/closed producer are refused before inventory calls. It reads ctx.plugin.list and ctx.tool.list, never check/update/reload/transform/execute. Lists are independently bounded to128 entries, dense, unique, defensive data properties and detached scalar copies; no execute or schema serialization. No arbitrary callback evaluation. Producer and adapter validate exact canonical returned location and current lifecycle under a whole-read deadline. After any await, Main rechecks original runtime epoch/workspace canonical path/trust/resource generation/revision; close/cancel/changed identity retires the result. This is two current inventories, not an atomic permission or execution snapshot.

Public request is configuration.extensions.read + workspaceId only in normal v2 envelope. Response contains runtimeEpoch, workspaceId, workspacePath, revision and closed plugins/tools groups plus hooks. Each supported group is available with rows or unavailable with reason runtime_unavailable|invalid_response|limit_reached and no rows. Invalid group is never silently truncated to valid empty success. Overall status available|partial|unavailable describes supported groups, not hook execution. Hooks is exactly status:not_reported, reason:inventory_not_supported. Group failures may be independent; no raw exception text is public.

Plugin rows contain bounded id, Native state active|failed, source builtin|package|local|sdk and server/tui/rpc booleans. Omitted Native feature flags normalize to false, never guessed capabilities. Failed rows use generic native_failed reason; raw error/ref omitted. A local source path is shown only if absolute, normalized/control-safe and bounded; it never authorizes file IO or project ownership. Package target is optional only for safe npm identifier/version grammar; unsupported/credential-bearing forms are omitted with unsupported_source reason, not echoed. Missing optional IDs may be represented as a non-authoritative anonymous row key derived from safe scalar fields plus stable occurrence only if identity is unambiguous; otherwise group unavailable. No prefix-based ownership or executable action is introduced. Tool rows contain bounded exact effective id and name only; presence is registered, not enabled/permission/executed. No input/output/description/options/execute function enters the public response. Final exact TypeScript/helper field syntax is frozen with producer tests before consumer handoff.

## Runtime evidence and limits
Main-owned synthetic probe uses actual production owner/preflight/supervisor/fixed plugin/service and contained fresh stores. Prove actual plugin rows/tool registry names, exact path/context, no Native check/update/execute/reload calls, same session/default/policy/config/file/app-journal state before/after reads, no project plugin sentinel execution, closed refusal/no effect, all owned Native/helper exits, full source/build/resource before-after identity. Existing bootstrap itself may create its single declared session; compare after bootstrap. Do not claim raw SDK acknowledgements prove no process/network activity without the source/negative sentinels and actual observations. Never launch real provider/model/private stores or production Main foreground. Unsupported platform or unverified Native shape fails closed. This read-only increment has no durable feature marker, migration or replay behavior. Initial PLAN/DESIGN_SPEC once; final independent CODE/RENDER after frozen actual evidence.
